# Support

Start with the [README](README.md), [documentation](docs/index.md), and
[test guide](tests/README.md).

For bugs, questions, and feature proposals, use
[GitHub issues](https://github.com/patware/Patware.PingTrace/issues). Search existing
issues first. Include the package version, `dotnet --info` output, relevant
configuration with secrets removed, and a minimal reproduction or clear question.
For bugs, describe the expected and actual behavior and include relevant logs.

Support is provided by community participation as availability permits; there is
no guaranteed response time or commercial support commitment.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.
