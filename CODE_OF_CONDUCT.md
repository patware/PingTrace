# Code of Conduct

Everyone participating in this project is expected to be respectful and
constructive, regardless of background, identity, experience, or ability.

Welcome questions, give actionable feedback, and discuss technical disagreements
without personal attacks. Respect privacy and requests to stop unwanted contact.

Harassment, discrimination, threats, sexualized attention, doxxing, and abusive
or deliberately disruptive behavior are unacceptable. These expectations apply
to project issues, pull requests, discussions, and other project spaces.

## Reporting and enforcement

The repository maintainer, [@patware](https://github.com/patware), handles conduct
concerns. Use a private contact method the maintainer makes available on their
profile, if available. Otherwise use GitHub's Report abuse controls for abusive
content or accounts. Do not post sensitive details in a public issue.

Maintainers may edit or remove inappropriate content, warn participants, limit
participation, or exclude participants for serious or repeated violations.
Reports should be handled with discretion, sharing details only as needed to
address the concern. Maintainers are expected to follow these same standards.
